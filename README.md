# odin-recipes

In this project of TOP I learned to use and implement the basics of HTML and git. I started by making a repository on github and cloning it to my pc.
I set up an index.html page and made directories for my recipe.html files and for my images. I learned to use the following HTML skills:
<ul>
<li>Creating the HTML boilerplate:</li>
    <li>setting my doctype to html</li>
    <li>setting the html language using lang="en"</li>
    <li>setting the charset to utf-8</li>
    <li>adding a title that will display in browser tabs</li>
<li>Use headings ranging from h1 to h6</li>
<li>Create paragraphs</li>
<li>Make bold text</li>
<li>Make italic text</li>
<li>Make ordered and unordered lists</li>
<li>Use anchor to link to websites via absolute urls or to other HTML files in my root directory using relative urls</li>
<li>Set anchor target to _blank to open link in a new tab and set rel to noreferrer for security</li>
<li>Use img src to link to images on other websites via absolute urls or to images in my root directory using relative urls </li>
<li>Add alt text to images for accessibility and set the height and width of my images</li>
<li>Use & ; to type out reserved characters</li>
<li>Use git add to add my changes to the staging area</li>
<li>Use git commit -m to commit my changes and write a short but detailed commit message (I think my messages could use some work)</li>
<li>Use git push origin main to push my changes to my remote repository on github</li>

I really enjoyed this project. It was fun to finally implement the stuff I've been learning so far. Throughout the project I had to go back to previous lessons
to refresh my memory. I also ran into a silly mistake where my lists would skip a line. I pasted my code into a validator and saw I accidentally typed l1 instead
of li. I look forward to improving my knowledge of HTML and to be able to build cool websites!
